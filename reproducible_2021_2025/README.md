# Almaty air quality: reproducible 2021–2025 analysis

This standalone code reproduces the corrected five-year experiment: four imputers
crossed with five regression algorithms and five classifiers (40 combinations).
It has no dependency on the authors' desktop paths or legacy six-month analyses.

## Install and run

Python 3.13 was used for the reference preparation environment. Use a fresh virtual
environment and the pinned requirements; recorded versions are in environment.json.

```sh
python -m venv .venv
# Activate .venv using your operating system's standard command.
python -m pip install -r requirements.txt
python run_pipeline.py --source /path/to/extracted_Kazhydromet --output /path/to/fresh_results
```

Input layout: `2021/`, ..., `2025/`, with extracted automatic `.xls` and optional
manual `.xlsx` workbooks anywhere below each year folder. RAR extraction is a
separate prerequisite. Workbook layouts and units must match the supplied format.
This release intentionally fixes the paper's train/validation/test periods to
2021–2023 / 2024 / 2025. Reusing on other periods requires modifying partition().

Alternatively, use the normalized annual inputs generated by import_sources.py:

```sh
python run_pipeline.py --normalized /path/to/annual_csv_partitions --output /path/to/fresh_results
```

Required normalized files: raw_observations_2021.csv.gz through
raw_observations_2025.csv.gz. Columns include timestamp, source_type, station_key,
station_raw, source_file and pollutant concentration columns. The supplied parser
produces this schema. Only observed automatic city NO2 forms predictive targets.
Manual records and ambiguous secondary blocks are exported separately.

## Methods and outputs

Mean, median, past-only linear extrapolation and standardized KNN (up to 2,000
training donors) use training-only statistics. Outcomes are not imputed. Exact
duplicate measurement vectors are removed, conflicting timestamps averaged and
all-core-zero records studied in separate retained/excluded scenarios. A
label-based fixed-network sensitivity is also run. Model selection uses 2024,
not 2025. Persistence is reported for regression and classification.

Outputs include corrected_comparison.xlsx, prediction files, complete joblib
preprocessing/estimator pipelines, features_imputed_*.csv.gz, source/duplicate
audit logs, verification_checks.csv, bootstrap intervals and publication figures.
verification_checks.csv and a successful process exit indicate numerical checks
passed; they do not verify physical station identity or measurement units.

`predict.py` accepts new chronological station-hour or city-hour concentrations.
For causal extrapolation, supply recent context before the forecast window.
Hourly values label completed aggregation bins: predict the next bin after the
current bin is complete, not at the beginning of the current bin.

## Data access and limitations

No raw measurements, author credentials or fitted models are included in this
public code release. Obtain data from the authors/data owner under the applicable
permissions. Complete reproduction requires those inputs; the code link alone
does not provide the dataset. Source identities, units and all-zero record status
require source-owner verification. File hashes are in SHA256SUMS.json.

Ridge + mean is a descriptive test winner, not the validation-selected model.
Do not retrospectively choose a model on the final test set.

## Publication figures and supplementary tables

```sh
python -m pip install -r requirements-figures.txt
python make_publication_assets.py --results /path/to/fresh_results --assets /path/to/figure_table_assets
```

This optional stage generates three main figures, fifteen supplementary figures
and eight supplementary CSV tables. TreeSHAP uses 100 evenly spaced test rows;
classifier permutation importance uses approximately 1,000 test rows and three
repeats. Interpretability is post-test description, not a model-selection step.
Old six-month SHAP/18-indicator plots are not reused as five-year evidence.
